Platform stack

The models, datasets, and tools behind VOXINSIGHT

This page documents the actual implementation used in VOXINSIGHT V2: the production CNN v2 classifier, the notebook SVM baseline used for benchmarking, the temporary wav2vec2 hook, the audio preprocessing chain, and the frontend and backend pieces that power uploads, recording, and analysis.

Model stack
Deployed model
EmotionCNNv2
This is the active production classifier in backend.py. It consumes 128-bin mel spectrograms and outputs six emotion classes: angry, disgust, fearful, happy, neutral, and sad.
Classical baseline
MFCC + SVM
Notebook experiments include an MFCC feature pipeline with an SVM baseline. This path is used for comparison and validation against deep-learning models, and its artifacts are stored under VOXINSIGHT_output/models.
Secondary model path
wav2vec2 hook
The backend also contains a temporary wav2vec2 sequence-classification path for future experimentation and comparison. It is loaded from the local VOXINSIGHT_output/models/wav2vec_best directory.
Training target
6-class emotion output
The deployed label set is standardized to six classes. Browser-facing copy may use friendlier names, but the model output is normalized to the backend label set.
End-to-end inference flow
01
Record or upload
Users capture audio in the browser or upload a file from the landing page or recording page.
02
Transmit to API
Frontend JavaScript posts the audio blob to the Flask API at /api/predict.
03
Preprocess audio
The backend converts the waveform into the representation expected by the model.
04
Run inference
PyTorch loads the CNN v2 weights and returns class probabilities.
05
Render results
The UI shows the dominant emotion, confidence, feature values, and the analysis plot.
06
Save history
Predictions are written to browser localStorage for a lightweight emotion history view.
